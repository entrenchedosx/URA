# Third-party materials

URA's existing source license is MIT; see LICENSE. Cargo.lock pins dependency
versions. Each dependency retains its own copyright and license. `object`,
`iced-x86`, `rusqlite`/SQLite, eframe/egui, egui_dock, egui_extras, rfd, image,
Clap, Tokio and rmcp provide parsing, decoding, persistence, rendering and
headless transport; they are not URA-authored implementations.

Release preparation uses `scripts/collect_licenses.py` to traverse the dependency
graph and gather declared licenses plus bundled license/notice texts. The
generated directory is included in the portable Windows package. It includes
build dependencies and may include some optional dependencies beyond the shipped
binaries. No package in the inspected locked metadata lacks a license declaration.
Inspect the generated missing-text report before redistributing binaries.

Notable obligations include bundled font licenses in epaint_default_fonts
(OFL-1.1, Ubuntu-font-1.0 and Hack), whose `OFL.txt`, `UFL.txt` and
`Hack-Regular.txt` sidecars are copied explicitly, plus Unicode data licenses,
Apache notices and MPL-2.0 components. Unmodified crate sources can be obtained
from the versions linked in the generated inventory. URA does not vendor or modify those components.
Windows system fonts are loaded from the host if present; their files are not
copied into the repository or package. egui's fallback fonts retain their notices.

The supplied icon.webp is the official URA artwork. Its owner confirmed permission
for public redistribution with URA on 2026-10-20. Generated PNG/ICO variants use
the entire image with transparent padding, without cropping or changing artwork.
The original is RGB, opaque, 474×346, with no embedded provenance metadata.
No separate attribution text was supplied.

Ghidra source was inspected, not incorporated. See docs/GHIDRA-RESEARCH.md for
pinned primary sources and provenance. IDA's screenshot was a layout reference;
no proprietary icons, screenshots, source or trademarks are bundled as URA assets.
The PE/ELF test fixtures are generated by scripts/generate_fixtures.py, not
third-party sample executables. System binaries used for local checks are not
distributed.
