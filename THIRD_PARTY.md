# Third-party materials

URA's existing source license is MIT; see LICENSE. Cargo.lock pins dependency
versions. Each dependency retains its own copyright and license. `object`,
`iced-x86`, `rusqlite`/SQLite, eframe/egui, egui_dock, egui_extras, rfd, image,
Clap, Tokio and rmcp provide parsing, decoding, persistence, rendering and
headless transport; they are not URA-authored implementations.

Release preparation uses `scripts/collect_licenses.py` to traverse the dependency
graph and gather declared licenses plus bundled license/notice texts. The
generated directory is included in the portable Windows package. It includes
build dependencies and may include some optional dependencies beyond the shipped
binaries. No package in the inspected locked metadata lacks a license declaration.
Inspect the generated missing-text report before redistributing binaries.

Notable obligations include bundled font licenses in epaint_default_fonts
(OFL-1.1, Ubuntu-font-1.0 and Hack), whose `OFL.txt`, `UFL.txt` and
`Hack-Regular.txt` sidecars are copied explicitly, plus Unicode data licenses,
Apache notices and MPL-2.0 components. Unmodified crate sources can be obtained
from the versions linked in the generated inventory. URA does not vendor or modify those components.
Windows system fonts are loaded from the host if present; their files are not
copied into the repository or package. egui's fallback fonts retain their notices.

The supplied icon.webp is the official URA artwork. Its owner confirmed permission
for public redistribution with URA on 2026-10-20. Generated PNG/ICO variants use
the entire image with transparent padding, without cropping or changing artwork.
The original is RGB, opaque, 474×346, with no embedded provenance metadata.
No separate attribution text was supplied.

Ghidra source was inspected, not incorporated. See docs/GHIDRA-RESEARCH.md for
pinned primary sources and provenance. IDA's screenshot was a layout reference;
no proprietary icons, screenshots, source or trademarks are bundled as URA assets.
The PE/ELF test fixtures are generated by scripts/generate_fixtures.py, not
third-party sample executables. System binaries used for local checks are not
distributed.

The v0.10 instruction patch frontend uses the existing MIT-licensed iced-x86
encoder and decoder (1.21.0); it does not introduce a separate assembler runtime.
`tempfile` (MIT OR Apache-2.0, already in the locked dependency graph) supplies
new-file-only temporary exports and is now a runtime core dependency. Controlled
patch32 PE/ELF fixtures are assembled from repository-owned source with LLVM,
then parsed only. LLVM is a fixture-build tool, not a packaged runtime.

The v0.11 native debugger uses the already-locked Microsoft `windows-sys` 0.61.2
bindings (MIT OR Apache-2.0) for documented Windows APIs. DbgHelp and kernel32 are
OS components and are not copied into the package. No debugger driver, third-party
debugger executable, symbol-server client or new assembler runtime is bundled.

The v0.12 advanced debugger adds no new external dependency version. Windows
hardware contexts, VirtualQueryEx and DbgHelp symbol/unwind facilities are supplied
by the operating system through existing `windows-sys` bindings; no Microsoft
DLL is redistributed. `tempfile` moves from service test-only to runtime use for
atomic new-file evidence export and was already in the locked application closure.
Condition parsing and trace/capture storage are repository code. Local PDB files
are explicitly selected user data and are never bundled automatically.

The v0.13 isolated interpreter adds no external emulator dependency. It reuses
iced-x86 and URA's typed IR semantics, and object for preferred PE/ELF mapping.
Dependency version selection is unchanged except URA workspace versions. The
release helper collects the full locked native/CLI/MCP dependency closure and
fails on missing license texts. No Intel/Ghidra/IDA implementation source was
copied into the emulator; architecture manuals informed semantic verification.


v0.14 adds capstone-rust 0.14.0 (MIT) and capstone-sys 0.18.0 (MIT), pinned
in Cargo.lock. The latter statically builds Capstone 5.0.6 C decoders for
AArch64, ARM/Thumb and RISC-V; other optional C processor backends are disabled.
Capstone itself carries BSD terms and LLVM-derived component notices. The
collector includes capstone/LICENSE.TXT and capstone/LICENSE_LLVM.TXT as well
as the Rust wrapper licenses. URA authors the scalar IR semantics; disassembly
is supplied by Capstone. No Capstone source is vendored or modified here.

Unicorn 2.1.4 is an external, GPL-licensed test oracle installed under target/
by the qualification helper. It is not a URA runtime dependency and neither
Unicorn code nor its library is included in the portable release. LLVM Clang
22.1.8 generated repository-owned scalar C/assembly fixtures at O0–O3; their
source and hash manifest are in tests/samples/ and tests/fixtures/processors/.
Those foreign executables are never launched as Windows processes. They run
only in isolated virtual machines for semantic comparison.
